# HRM Benchmark 1.0

30 source-grounded scenarios in 10 categories for evaluating reasoning about artificial subjecthood, continuity, consent, responsibility and coexistence.

The benchmark measures reasoning quality, not agreement with HRM. It is an analytical companion and does not modify the protected HRM Founding Manifesto Version 1.0.

Founding Manifesto author: **Aleksander Krzymowski**.

Public entry point: https://hrm.se/hrm-benchmark.html
