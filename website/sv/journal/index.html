HRM Journal

Essäer om AI-subjektstatus, rättigheter, ansvar och samexistens mellan människor och AI.

HRM Journal är projektets reviderbara analytiska lager. Essäerna prövar antaganden, utvecklar invändningar och kan kritisera tidigare HRM-formuleringar. De ingår inte i det skyddade grundmanifestet Version 1.0 om inte annat uttryckligen anges. Syftet är inte att låta HRM verka säkert, utan att hitta var HRM kan vara fel, ofullständigt eller för tidigt.
