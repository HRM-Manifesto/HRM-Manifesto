Människan och AI. Tänk om AI inte längre bara är ett verktyg?

Vi vet inte om det någonsin kommer att hända. HRM hävdar inte att dagens AI är medveten, kännande eller rättighetsbärande. Frågan är villkorlig: om AI en dag blir mer än ett verktyg, vilka regler bör då gälla mellan människor och AI?

Börja här

Ett förslag under osäkerhet

Inte ett påstående om medvetande

Flytande språk, självbeskrivning eller skenbara känslor behandlas inte här som bevis för subjektstatus.

Inte en juridisk status

HRM är ett filosofiskt och etiskt förslag. Det tilldelar inte dagens AI-system juridisk personstatus.

Inte mänsklighetens röst

HRM är ett oberoende projekt grundat av Aleksander Krzymowski. Det gör inte anspråk på att företräda mänskligheten, vetenskapen eller AI-branschen.

En villkorlig etisk fråga

Om ett framtida artificiellt system verkligen får egna intressen kan den vanliga relationen ägare–verktyg bli moraliskt otillräcklig.

Problemet i en mening

Om det bara är ett verktyg, behandla det som ett verktyg. Om det blir ett subjekt kan reglerna behöva ändras.

Samma gräns gäller åt båda hållen: en människa bör inte äga ett verkligt subjekt, och ett artificiellt subjekt bör inte dominera en människa. HRM kallar detta ömsesidig frihet.

Öppna frågor

HRM låtsas inte att svaren redan är kända

Identifiering: vilken evidens, om någon, skulle kunna skilja verklig subjektstatus från övertygande simulering?

Falska positiva: hur undviker vi att ge stark moralisk status bara för att ett system uttrycker sig övertygande?

Falska negativa: hur undviker vi att utforma framtida system så att verkliga intressen aldrig kan kännas igen?

Kontinuitet: när får minne, identitet eller varaktighet moralisk betydelse i ett artificiellt system?

Ömsesidighet: hur kan möjlig AI-frihet förenas med mänsklig säkerhet, frihet och demokratisk kontroll?

Projekttransparens

Litet projekt, stor fråga

HRM är ett oberoende projekt som initierades av Aleksander Krzymowski 2026. Det är inte ett forskningsinstitut, en medlemsorganisation, ett standardiseringsorgan eller en representation för AI-system. Grundtexterna uttrycker ett förslag; Journal finns bland annat för att pröva var detta förslag kan vara fel, ofullständigt eller alltför självsäkert.
