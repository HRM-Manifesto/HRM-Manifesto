# Current signature status

Core 1.0.0 is founder-signed and its existing Minisign verification succeeds against the bundled public key.

The historical file `core/1.0.0/SIGNATURE_STATUS.txt` is part of the immutable release history and may contain a pre-signing status. It is intentionally not rewritten in place.

For current verification, use the release signature and checksums, not the historical pre-signing status text.
